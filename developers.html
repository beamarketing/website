Quality Metrics & Validation Approach

Perception-critical KPIs — not generic video metrics.

For automotive OEMs, "good quality" is not PSNR. It is whether downstream perception, fusion and planning behave identically on compressed inputs. Every Beamr release is measured against the KPIs below.

Per-frame integrity
Every frame is scored independently. We flag any frame where pixel-region or feature-region distortion exceeds the perceptual threshold.
Reference: original sensor stream
Edge & feature preservation
Edge maps, gradient histograms and ORB/SIFT keypoint stability between source and compressed — the features perception models actually consume.
Edge IoU · Keypoint match rate
Optical flow & temporal consistency
End-point error of dense optical flow (RAFT/PWC-Net) between consecutive frames. Temporal coherence checked over multi-second windows.
EPE · Flow drift · Frame-to-frame variance
Object, lane & sign detection
mAP / IoU on cars, pedestrians, cyclists, lanes, and traffic signs measured on original vs. compressed for the same model checkpoint.
mAP · IoU@0.5 · F1 stability
Reasoning & tracking stability
MOTA/IDF1 for multi-object tracking and trajectory prediction stability on compressed inputs vs. originals over long temporal windows.
MOTA · IDF1 · ID switches
Behavioral parity downstream
Maneuver planning, brake commands, and steering deltas are compared on the compressed pipeline vs. the reference pipeline. Divergence must be statistically indistinguishable from sensor noise.
Δ-trajectory · Δ-control output

Quickstart

Drop-in for any video pipeline.

Beamr ships as a CLI, an SDK (C/C++/Python), and a GPU-native pipeline compatible with NVIDIA Video Codec SDK and DALI. Use it on raw drive logs, curated AI corpora, or in-vehicle ECU offload paths.

Read the SDK Reference → Request access
beamr_optimize.py 
# Optimize a drive-log MP4 with perception-accuracy guard
from beamr import Optimizer, PerceptionGuard

opt = Optimizer(
    codec="hevc",           # H.265
    target_savings="40%+",
    guard=PerceptionGuard(
        models=["yolov8-auto", "raft-flow"],
        max_map_delta=0.005,    # 0.5%
        max_flow_epe=0.10,     # pixels
    ),
)

result = opt.run(
    src="drive_2026_05_04.mp4",
    dst="drive_2026_05_04.beamr.mp4",
)

print(result.savings_pct, result.perception_delta)
# → 42.1   <0.3% mAP   0 ms latency

Glossary

Key terms used across Beamr documentation.

A shared vocabulary so video, ML and OEM safety teams describe the same thing the same way.

Perception Accuracy Pₐ
Primary quality reference for automotive workloads: how well a downstream perception model performs on the compressed stream vs. the uncompressed source, not pixel similarity.
CABR Content-Adaptive
Beamr's content-adaptive bitrate engine. Allocates bits per region/frame based on perceptual and feature importance — not a fixed quantization curve.
Per-frame Integrity
A guarantee that no individual frame degrades below a perceptual threshold — important because perception models can fail on a single bad frame.
Edge & Feature Preservation
Stability of edges, gradients and ML keypoints across compression. The signal that detectors and trackers actually consume.
Optical Flow Consistency EPE
End-Point Error of dense flow estimation. Measures whether motion vectors used by trackers and predictors remain valid post-compression.
Behavioral Divergence
Any difference in the maneuver-planning or control output between the compressed pipeline and the reference pipeline. Beamr targets zero divergence.
NVIDIA Cosmos Curate
NVIDIA's curated dataset and ingestion framework for autonomous-driving AI. Beamr H.265 outputs are compatible with Cosmos Curate ingestion.
ASIL-relevant Scenarios
The driving scenarios with safety implications — low light, fog, long range, emergency braking, lane-change. Beamr publishes results across all of them.
